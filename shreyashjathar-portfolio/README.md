# Shreyash Jathar Portfolio

A responsive, dark-themed personal portfolio built with plain HTML, CSS and JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Before publishing
- In `index.html`, replace `YOUR_EMAIL@example.com` with your real public contact email.
- Replace the LinkedIn placeholder URL with your profile.
- Add a resume PDF if you want a resume download link.
- Review the education and internship descriptions to ensure they are current and accurate.

## Deploy
You can deploy this folder using Netlify, Render Static Sites, GitHub Pages, or any static hosting provider. For Netlify, drag the extracted folder into the deploy area or connect the GitHub repository.
